GitHub Actions workflow 
name: Deploy Static Website to AWS S3

on:
  push:
    branches:
      - main

jobs:
  deploy-the-static-site-to-s3:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout repository
        uses: actions/checkout@v5

      - name: Configure AWS Credentials
        uses: aws-actions/configure-aws-credentials@v5
        with:
          aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID }}
          aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
          aws-region: eu-central-1

      - name: Deploy website to S3
        run: |
          aws s3 sync . s3://YOUR_BUCKET_NAME --delete \
            --exclude ".git/*" \
            --exclude ".github/*" \
            --exclude "README.md" \
            --exclude "images/*"

Quick Troubleshooting

Access Denied

Check public access, bucket policy, and S3 website endpoint.

AWS Auth Fails

Verify GitHub Secrets and IAM access key status.

Wrong Region

Match workflow region with bucket region.

No Deployment

Confirm you pushed to the main branch.
